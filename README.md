
# Melissa Contreras — Product Design Portfolio

Bilingual (EN/ES) portfolio of case studies in B2B product design and data-driven UX.

**How it was built:** I wrote the product brief and structured prompts with ChatGPT,
generated the first version in Lovable, then iterated on layout, content hierarchy,
and the bilingual system. Deployed on Vercel.

Stack: React, TypeScript, Tailwind, Vite.
